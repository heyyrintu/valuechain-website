# SEO, AEO, GEO and AIO setup

Everything below is generated by `scripts/build.mjs` from `scripts/site.config.mjs`. Nothing is hand-edited in `out/`.

## SEO (search engines)
- A unique `<title>` (under ~60 characters) and meta description (under ~160) on every page.
- An absolute `<link rel="canonical">` on the apex domain `https://dronavaluechain.com`. nginx 301-redirects `www` to the apex.
- Clean trailing-slash URLs (`/about/`). The old `.html` paths 301 to them.
- `robots` meta with `max-image-preview:large` and `max-snippet:-1`. The 404 page is `noindex`.
- `hreflang` `en-IN` and `x-default`. `<html lang="en-IN">`.
- `sitemap.xml` with lastmod, priority and image entries. `robots.txt` points to it.
- Open Graph and Twitter cards with a 1200×630 image (`assets/brand/og-image.png`).
- Web app manifest, apple-touch icon and theme colour.
- A `<main>` landmark, one `<h1>` per page, alt text on images, lazy-loaded below-the-fold images.
- A custom 404 page.
- **Old site migration:** old service, industry, blog and clients URLs 301 to the nearest new page (see `nginx.conf`), so existing rankings carry over.

## AEO (answer engines, featured snippets, voice)
- `FAQPage` JSON-LD on Home and Contact, where the FAQ is visible on the page.
- `speakable` markup that points at the H1 and intro copy.
- `BreadcrumbList` on every inner page.

## GEO (local and geographic)
- `Organization` + `LocalBusiness` JSON-LD with full address, geo coordinates, phone, email, CIN, founders, area served (India) and contact point.
- `geo.region`, `geo.placename`, `geo.position` and `ICBM` meta.
- The same name, address and phone on every page, in the schema and in llms.txt.

## AIO (AI search: ChatGPT, Claude, Perplexity, Gemini, Copilot)
- `robots.txt` explicitly allows GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, Claude-SearchBot, PerplexityBot, Google-Extended, Applebot-Extended, Bingbot, CCBot and others.
- `/llms.txt`: a short factual summary, key facts, page index and FAQs.
- `/llms-full.txt`: the plain text of every page, regenerated on each build.
- One linked JSON-LD `@graph` per page, so every fact resolves to one entity (`#organization`). It includes `Service` nodes for the six services and a `knowsAbout` topic list.
- An IndexNow key file is published at `/<indexNowKey>.txt` for Bing and Copilot.
